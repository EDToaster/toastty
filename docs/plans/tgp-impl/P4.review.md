## Issues

### P4-V1 — low — P4-T7 emits `unknown_op` for an unrecognized anim verb, a code G12.3 row 8 marks RESERVED

**Problem.** `unknown_verb_errors_unknown_op` (P4-T7, line 166) asserts an out-of-set anim verb
(`frobnicate`) draws `tgp;x;code=unknown_op`. G12.3 row 8 lists `unknown_op` as RESERVED with "no
ingress trigger" because unknown patch OPS are skipped, not fatal (s07.3 forward-compat). So a P4 test
emits a code the addendum's reachability table marks unreachable. The plan declines to rewrite this
(cleanup log line 373) on the ground that anim verbs are a closed control-frame enum (S14.3), always
fully parsed (S07.2), not a skippable patch op — so the reserved-`unknown_op` ruling is scoped to the
patch-op-skip path and does not reach the closed anim-verb enum. That reading is internally coherent
and the decline is openly flagged for the design owners.

**Why low, not blocking.** This is a genuine seam the addendum's row 8 did not contemplate (a closed
*control-frame verb* enum, distinct from the *patch-op* skip path), and the plan resolves it
transparently with an explicit decline rather than silently. It is the design's own S14.3 intent. But
strictly, G12.3 marks `unknown_op` RESERVED for ALL ingress, and a literal reading of "error codes
match the G12 table" is in tension with a P4 test emitting it. The risk is purely a taxonomy
disagreement (which closed code labels a closed-control-frame-verb violation), not a correctness or
isolation defect.

**Fix (design-owner call, optional for the phase).** Either (a) the design owners ratify that closed
control-frame verb violations use `unknown_op` and amend G12.3 row 8 to note this second reachable
locus (the addendum is authoritative, so the table should reflect it); or (b) funnel the
closed-verb-set violation through an already-REACHABLE code — `bad_param` (row 16, "out-of-range/invalid
op field") or `unsupported` (row 18) — and rewrite `unknown_verb_errors_unknown_op` accordingly. Option
(a) is the smaller change and matches the design's stated intent; either removes the table tension. No
coverage is lost under either.
