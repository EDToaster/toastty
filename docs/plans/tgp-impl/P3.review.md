- The only places the string `denied` appears as an *emitted* code are inside the historical "Review resolution log (round 2)" (line ~325, describing the SUPERSEDED P3-T4b draft and its since-renamed test). Those are log/audit-trail entries, not live task spec, and the "Cleanup resolution log (pass 1)" + the live task bodies override them. No LIVE test asserts a `denied` reply.
