# P1 verify (pass 1)

Verification of the revised P1 (Foundation) plan against the authority chain: **G11/G12 reconciliation addendum (authoritative) > base spine (G1–G10) > design slices §5–§8/§11**. P1 is the pure-CPU TGP spine end to end: APC back-channel + binary-read framer (+`trl=1` trailer), TGP text-header parse, CBOR patch decode, always-answered handshake/caps, retained per-token scene (u64 revisions + dirty flags), world matrices, atomic patch apply, `node.instances` decode/validate, chunked reassembly, inline GLB decode, `tgp;x`/`tgp;a` emitters, forward-compat skip, one viewport + default material rendered at compositing parity, RIS/DECSTR teardown, deterministic clock.

This pass re-verifies after the cleanup pass that (a) applied R3-1..R3-7, (b) applied the G11/G12 addendum (private per-token id map; `denied`/`msg_too_large`/`unknown_op` RESERVED; `instanced_node_tint→kind_conflict`), and (c) assigned the three canonical-owner dedup duties (T12 instances, T16 error enum+emitter, T17 ack emitter).
